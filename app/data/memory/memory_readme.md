# Memory Data

This folder stores various logs of system memory used for processing interactions and maintaining AI context over time.

## Key Files
- **episodic_memory.md**: Logs specific interaction events.
- **long_term_memory.md**: Archives persistent long-term memories.
- **procedural_memory.md**: Documents step-by-step procedural operations.
- **semantic_memory.md**: Contains insights and general knowledge data.
- **short_term_memory.md**: Stores transient context.
- **working_memory.json**: Reflects active working memory for real‑time processing.

## Logic and Interconnections
- Memory files are frequently written and read by the memory module in `features/memory/`.
- **Recommendation**: Evaluate consolidation strategies for improved retrieval and maintainability.
