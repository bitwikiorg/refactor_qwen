# Utility Functions

This folder provides helper functions and type definitions essential for various system operations, including assertions, object manipulation, and system status metrics.

## Key Files
- **assertions.d.ts & assertions.js**: Provide assertion functions for testing.
- **object-utils.d.ts & object-utils.js**: Functions for object inspection and manipulation.
- **systemStats.mjs**: Collects and reports system performance and statistical data.

## Interconnections and Logic
- Utilities are imported by multiple modules for consistency and error checking.
- **Recommendation**: Keep utility functions modular to ease maintenance and testing.
